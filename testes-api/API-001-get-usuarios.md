# API-001 - Consultar usuários

**Método:** GET  
**Endpoint:** `https://jsonplaceholder.typicode.com/users`

## Objetivo

Validar se a API retorna corretamente a lista de usuários cadastrados.

## Resultado esperado

- Retorno com sucesso
- Status HTTP `200 OK`
- Resposta em formato JSON
- Lista de usuários retornada
- Cada usuário deve possuir dados como `id`, `name`, `username` e `email`

## Resultado obtido

A API retornou com sucesso a lista de usuários em formato JSON, com status HTTP `200 OK`.

## Status

✅ PASS

## Evidência

Evidência da execução realizada no Postman.
