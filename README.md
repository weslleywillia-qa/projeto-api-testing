# 🔌 Projeto de API Testing

Projeto desenvolvido para demonstrar conhecimentos práticos em testes de APIs REST, utilizando Postman e validações de requisições e respostas HTTP.

## 🎯 Objetivo

Executar testes funcionais em uma API REST, validando endpoints, códigos de status, dados retornados e comportamento das requisições.

## 🛠️ Ferramentas

- Postman
- API REST
- JSON
- HTTP
- Git
- GitHub

## 🌐 Métodos HTTP testados

- GET
- POST
- PUT
- DELETE

## ✅ Validações realizadas

- Status Code
- Tempo de resposta
- Estrutura do JSON
- Campos obrigatórios
- Dados retornados
- Mensagens de erro
- Criação de registros
- Atualização de registros
- Exclusão de registros

## 📁 Estrutura do projeto

- `testes-api/` — documentação dos testes
- `postman/` — collection exportada do Postman
- `evidencias/` — evidências das execuções

## 📊 Casos planejados

| ID | Método | Cenário |
|---|---|---|
| API-001 | GET | Consultar usuários |
| API-002 | POST | Criar usuário |
| API-003 | PUT | Atualizar usuário |
| API-004 | DELETE | Excluir usuário |

## 📚 Aprendizados

Este projeto busca desenvolver experiência prática em testes de APIs REST, interpretação de respostas JSON, códigos HTTP e documentação de resultados.
